# Social App Roadmap (Web First)

更新时间：2026-08-02

## 1. 产品版本

- 1.0：基础账号、关系链、聊天与拉黑系统
- 2.0：完整社群系统
- 3.0：动态 / 朋友圈

产品优先级：

1. 聊天
2. 社群
3. 动态 / 朋友圈 / Feed

## 2. 当前能力

- 账号注册、登录、JWT、资料更新和头像上传
- WebSocket 私聊、群聊、会话列表、消息列表和已读状态
- 关注、粉丝、互关和拉黑
- 玩家群资料、公告、成员角色、邀请、申请审批、群主转让、退群和解散
- 官方固定话题聊天室（当前为内存态）
- React 前端与本地 `shadcn/ui` 风格组件
- Develop Loop：需求/设计/独立测试设计与评审、行为规格追溯，以及按 docs / engineering / develop 分类的本地与 GitHub Actions 质量门禁

## 3. 近期建设重点

- 将官方话题房统一到持久化社群模型
- 完善社群管理操作审计和交互反馈
- 收敛白名单免密、跨域、WebSocket Origin、默认密钥和上传校验
- 验证长连接稳定性、部署回滚、性能和运营工具
- 启动动态 / Feed 建设
- 按业务域持续扩展行为规格、回归用例和 Mutation 保护范围

## 4. 后续方向

### 聊天稳定性

- 收敛连接重连、消息一致性和错误处理
- 建立新的行为规格、自动化测试和真实 WebSocket 集成验证

### 社群系统

- 持久化官方群与频道
- 统一官方群和玩家群模型
- 完善 owner/admin/mod/member 权限与操作审计

### 发布准备

- 以 GitHub Actions 作为唯一 CI，并在此基础上补齐镜像、部署与回滚链路
- 完成安全配置、性能和稳定性验收

### 动态 / Feed

- Phase A：纯文字动态
- Phase B：图文动态
- Phase C：规则排序，再评估推荐算法
