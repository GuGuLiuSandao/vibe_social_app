# Social App Roadmap (Web First)

更新时间：2026-08-01

## 1. 产品版本

- 1.0：基础账号、关系链、聊天与拉黑系统
- 2.0：完整社群系统
- 3.0：动态 / 朋友圈

产品优先级：

1. 聊天
2. 社群
3. 动态 / 朋友圈 / Feed

## 2. 当前能力

- 账号注册、登录、JWT、资料更新和头像上传
- WebSocket 私聊、群聊、会话列表、消息列表和已读状态
- 关注、粉丝、互关和拉黑
- 玩家群资料、公告、成员角色、邀请、申请审批、群主转让、退群和解散
- 官方固定话题聊天室（当前为内存态）
- React 前端与本地 `shadcn/ui` 风格组件

AI NPC 功能已于 2026-08-01 从当前产品基线移除。

## 3. 当前缺口

- 官方话题房尚未统一到持久化社群模型
- 社群管理缺少完整操作审计和细致交互反馈
- 白名单免密、跨域与 WebSocket Origin、默认密钥和上传校验尚未达到生产要求
- 长连接稳定性、部署回滚、性能和运营工具尚未验收
- 动态 / Feed 尚未开始
- 自动化测试和旧研发流水线已暂时移除，等待新的 Develop Loop 设计后重建

## 4. 后续方向

### 聊天稳定性

- 收敛连接重连、消息一致性和错误处理
- 建立新的行为规格、自动化测试和真实 WebSocket 集成验证

### 社群系统

- 持久化官方群与频道
- 统一官方群和玩家群模型
- 完善 owner/admin/mod/member 权限与操作审计

### 发布准备

- 明确唯一 CI/CD 平台
- 建立构建、检查、镜像和部署回滚链路
- 完成安全配置、性能和稳定性验收

### 动态 / Feed

- Phase A：纯文字动态
- Phase B：图文动态
- Phase C：规则排序，再评估推荐算法
