# Social App Roadmap (Web First)

更新时间：2026-08-01

## 1. 产品目标与范围

## 版本口径（已确认）
- 1.0：当前基础功能 + 拉黑系统
- 2.0：在 1.0 基础上完成完整社群系统
- 3.0：在 2.0 基础上增加动态 / 朋友圈

优先级（已确认）：
1. 聊天
2. 社群
3. 动态/朋友圈/Feed

MVP（Web）范围（已确认）：
- 必须有：私聊、群聊、官方社群、玩家自建社群、社群管理、拉黑玩家
- 暂不做：个人动态列表、Feed 推荐算法、视频内容
- 动态迭代顺序：纯文字 -> 图文 -> 视频（后置）

## 2. 当前基线（代码现状）

已具备：
- 账号系统（注册/登录/JWT/资料更新/头像上传）
- WebSocket 聊天（会话、消息、已读、私聊/群聊创建）
- 关系链（关注/粉丝/互关）
- 官方固定话题聊天室（内存态）

已完成的后续扩展：
- 拉黑系统 V1：双向聊天/建私聊/邀请拦截、关系清理与前端入口
- 玩家群管理 V1.1：资料、公告、角色、邀请/申请、转让、退群与解散
- 前端基础控件迁移到 `shadcn/ui`，完成登录页、聊天页和群管理首轮视觉收敛
- AI NPC 聊天 MVP：默认 NPC、持久化记忆与 OpenAI 兼容 `chat/completions` 接入

主要缺口：
- M0 回归与收口未完全结束：缺双账号手工回归记录和可回滚标签
- 官方话题房仍为内存态，尚未统一到持久化社群模型
- 社群管理仍缺完整操作审计、WS/页面集成测试和细致交互反馈
- 发布准备尚未完成：长连接稳定性、部署回滚、性能与运营工具未验收
- 生产安全尚未收口：白名单免密、跨域/WS Origin、默认密钥、上传校验需要在发布前加固
- 动态/Feed 尚未开始

工程状态（2026-08-01）：
- `master` 工作区在健康检查开始前为干净状态，本地比 `origin/master` 超前 4 个 AI NPC 相关提交
- 后端 `go test ./...`、`go vet ./...` 通过；前端 7 个测试文件 / 18 个测试和生产构建通过
- Docker daemon 当前未运行，因此未验证本轮真实服务启动与双账号联调
- 维护热点：`frontend/src/pages/Chat.jsx` 与 `backend/internal/service/chat_service.go` 职责过度集中，需独立重构

## 4. MVP 后路线（动态/Feed）

Phase A（优先）：纯文字动态（发帖、评论、点赞、时间流）
Phase B：图文动态（上传与审核）
Phase C：Feed 排序（先规则后算法）

## 5. 单人 + AI 执行方式

- 周节奏：周一计划、周二到周四开发、周五测试与修复
- 每周输出：可演示功能 + 测试结果 + 风险清单
- 功能交付流程：需求设计文档 -> 技术方案文档 -> 功能开发 -> Code Review -> Commit
- 功能文档归档：按需求在 `docs/features/<feature-name>/` 下沉淀 `requirement.md`、`technical-solution.md`、`code-review.md`
- Definition of Done：
  - 功能可运行
  - 至少一条自动化测试
  - 文档更新（README/ROADMAP/M0_TASKS + 对应功能目录文档）
