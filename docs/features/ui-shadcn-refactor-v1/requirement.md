# 需求设计文档

## 1. 需求名称
- 前端 UI 重构 V1（shadcn/ui 统一化 + 留白优化）

## 2. 背景
- 当前前端主要使用自定义 Tailwind 组合样式与 `@vercel/examples-ui` 的 Button/Input 封装。
- 页面视觉密度偏高，模块间留白不足，聊天页在移动端与桌面端均存在压迫感。
- 本次需求要求将整体 UI 组件统一到 `shadcn/ui` 组件体系，并在不改变核心业务流程的前提下优化信息层级与空间节奏。

## 3. 目标
- 统一前端基础组件体系到 `shadcn/ui`（Button/Input/Textarea/Card/Badge 等基础件）。
- 在登录页、聊天页、群管理相关子组件中完成视觉重构与组件替换。
- 通过增加模块间距、区块留白、卡片内边距与列表行高，降低页面压迫感。
- 明确并固化工程规则：后续新增 UI 默认优先使用 `shadcn/ui`。

## 4. 用户价值
- 交互一致性更高，按钮、输入框、卡片风格统一。
- 信息更易读，视线停留与扫描路径更自然。
- 在复杂聊天场景下仍能维持清晰结构，减少认知负担。

## 5. 功能范围
- 包含：
  - `AGENTS.md` 增加 UI 组件规范（统一使用 `shadcn/ui`）
  - `frontend` 侧基础 UI 组件库替换（移除 `vercel-ui` 依赖路径）
  - `Login` / `Chat` / 群管理子组件视觉与间距重构
  - 全局样式变量调整（保留现有主题切换能力）
- 不包含：
  - 聊天/关系链/群管理的业务协议与后端逻辑变更
  - 新增产品功能点（仅做 UI/UX 收敛）

## 6. 验收标准
- 前端页面不再依赖 `frontend/src/lib/vercel-ui.js`。
- 登录页与聊天页主要交互控件均使用 `shadcn/ui` 组件。
- 聊天三栏布局在桌面端可读性提升，卡片与列表项留白明显增加。
- 移动端侧边区块与主内容区间距改善，不出现明显拥挤堆叠。
- `AGENTS.md` 明确新增 UI 组件统一约束。
- `cd frontend && npm test` 通过。

## 7. 风险与注意事项
- `Chat.jsx` 为高复杂度页面，UI 重构容易引入事件绑定回归。
- 组件替换需避免影响测试中依赖的文案与可访问性标签。
- 主题变量改造需兼容既有 dark/light/cold/neon 四种模式。
